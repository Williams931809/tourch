# Torch Bearers Academy

Secure school management application powered by Supabase and Vite.

## Setup

Run `npm install` and `npm run dev`. To build: `npm run build`.

Supabase project: `kzlzrdqsotbttfsiumbc`.

## Status

This is an initial implementation and must not be used with real student data until row-level security, admin provisioning, enrollment, marking, parent access and AI integrations are completed and audited. Do not enable public signups.
